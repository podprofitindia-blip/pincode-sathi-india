# Pincode Tool V1

A simple mobile-first India Pincode + Post Office lookup website.

## Features
- 6-digit Pincode lookup
- Post Office / area name search
- Delivery / Non-Delivery status when available
- Office type, district, state, circle, region and division
- One-tap copy of result address
- Google Maps search button
- Mobile-first responsive design
- No build step: plain HTML/CSS/JavaScript
- GitHub Pages friendly

## Data/API
V1 uses the public Pincode API at:
https://api.pincodeapi.in/api/v1

The API documentation states that the free Starter plan supports PIN lookup and search, with a public rate limit. Check the provider's current terms before high-volume/commercial use.

India's Open Government Data portal also publishes an All India Pincode Directory through web service, maintained by the Department of Posts.

## Important
This is an independent utility and is NOT an official India Post website.
Courier delivery availability can differ from postal Delivery/Non-Delivery status.

## GitHub Pages
1. Create a GitHub repository.
2. Upload `index.html`, `style.css`, `app.js`, and `README.md`.
3. Settings → Pages → Deploy from branch → main → /root.
4. Open the generated Pages URL.
